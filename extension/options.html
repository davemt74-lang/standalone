Annotated extension setup

If your Annotated website is already open, the sidebar will detect it automatically. Use this page only to set or change the server manually.

Permissions in plain language

Annotated reads the active page when you use it, captures only what you explicitly select, uses tab capture only for user-started media clips, and stores a revocable Annotated extension session. Login and account creation happen directly in the sidebar against the same Annotated account database as the website.
